# LOGIN-WATER：登入頁改為「深潭」水面版（短規格與計畫）

依人類 2026-10-28 提供原型 `login-water-e2.html`（方案 E2 深潭）並指示「把登入介面改成這個」；登入成功的轉場選「播完再進（約 1.5 秒）」。依 WORKFLOW §14（精簡流程）。

## 展示目標

登入頁全畫面是會流動的深綠水面（WebGL），左上角品牌，中間一張霧面玻璃卡片：PROJECTFLOW 小標、「登入專流」、副標「讓每一件工作，順著流程走到底。」、公司／帳號／密碼與「登入」按鈕。點水面、點進輸入框、按登入時水面起漣漪；輸入框聚焦時底部有水波；按登入時按鈕內水位上升。帳密錯誤時顯示錯誤並讓卡片左右晃一下。登入成功時卡片沉下、水從中間往兩側撥開並濺起水花，約 1.5 秒後進入工作台。

## 範圍

- 照原型的視覺、文案與動畫；不顯示原型的提示列、預填示範帳密、「歡迎回來」畫面與「回到登入畫面」按鈕（AI 代決：這些只是原型示意）。
- 登入流程、API、錯誤訊息、強制改密碼、記住的公司代碼等行為不變；只在登入 API 成功後、載入工作台前等待撥水動畫。
- 系統設定為減少動態效果、或瀏覽器不支援 WebGL 時：不等待、直接進入；不支援 WebGL 時保留深綠漸層背景。
- 不新增依賴、不從外部載入字型或資源（原型的 logo 改用內嵌 SVG）。

## 允許修改的檔案

`web/src/App.tsx`（登入區塊改用新元件、成功後等待轉場）、新檔 `web/src/components/LoginScreen.tsx`、`web/src/styles.css`（登入相關樣式）、登入相關 Vitest、`docs/PROGRESS.md`、本文件。

## 步驟

1. 開 `feature/login-water`。
2. Vitest：登入頁有「登入專流」、三個欄位與登入按鈕；錯誤時顯示訊息並保留欄位；成功後進入工作台（測試環境無 WebGL，不等待）。
3. 新增 `LoginScreen.tsx`（水面 shader、水花、漣漪、卡片），`App.tsx` 改用它。
4. Vitest 全量、build；15173 部署後 1280／375 實測：水面、輸入框水波、錯誤晃動、成功撥水後進入工作台、無水平捲動。
5. 一次獨立唯讀審查、記錄、`--ff-only` 合併。

## 驗收情境

- 1280 與 375：水面在動、卡片置中、無水平捲動。
- 錯誤密碼：出現「帳號或密碼不正確」類訊息，卡片晃動，可再輸入。
- 正確帳密：約 1.5 秒撥水後進入「所有專案總覽」。
- 減少動態效果：不播動畫，直接進入。
