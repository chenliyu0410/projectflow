# RAG-IMPL：正式文件 RAG 四模組整合短規格／計畫

依人類 2026-10-21「變成全部都我做，你可以開始了…自己開分身同時跑」執行；沿用已確認 RAG-PACK4-V2。採 WORKFLOW §14 的一次整合交付、獨立審查與相關完整回歸。此檔同時為本階段短規格。

## 交付邊界

一條完整路徑：既有正式文件上傳 → 可重試索引 → 經即時授權的檢索 → 本機生成／明示檢索降級 → 精確版本引用 → 回饋與管理者統計。保留既有 `/ai/*` 合成展示與 SQL。不部署、不動使用中資料、不合併或推送既有審閱中分支。

A：TXT/CSV、文字 PDF、DOCX；限制文字、頁數、解壓量；父段落與子切片、來源 hash、版本、狀態與重試。使用既有文件 immutable storage。每次儲存文件時於同 transaction 標 queued，索引由有編輯權者明確啟動（同步有界請求，可失敗重試），不用不可靠的 process-local background task。無 OCR。知識可停用／恢復，停用不刪原檔；重新索引先完整建立再發布。新版未 ready 不引用舊版。

B：中文雙字／英文詞 BM25，Ollama 真實 embedding，exact cosine＋RRF；第一版向量存 PostgreSQL JSON／SQLite JSON，非 ANN／pgvector。無模型時可用 BM25 並明示降級；向量模型設定變更後舊向量不混用。規則重排明確標示，非 neural reranker。父片段再授權、去重、有界 context；關鍵字同義展開與可選前次問題作多輪明確脈絡。每份最多 200 chunks、每次最多 5000 已授權 chunks、context 8000 字；超額明確報錯。

C：獨立 `/rag/*` 與正式文件 UI。設定公司專屬內網 Ollama chat/embedding 模型（本機 admin）；只依來源、引用集合驗證、資料不足不猜、錯誤降級、取消與晚回應隔離。模型 adapter 測試與真模型品質驗收分開；沒有已配置模型不宣稱真推論通過。

D：重用 session／正式文件權限，不創造另一套 ACL。查詢前、送模型前、回答與引用開啟時重新授權與檢查現行版。Trace 保存 ID、耗時、數量與版本，不存問題／答案／文件內容／token。回饋只屬於該公司該使用者的問答。固定合成評測與報告包含越權、過期來源、拒答、無效引用與降級；耗時只報實測，費用／token 無資料為 null。

## 共用介面（正式資料皆 synthetic:false, source_mode:formal）

- `GET /rag/status?project_id=`：projects[{project_id,title}]、project_id、can_configure、model{enabled,name,embedding_model}、counts、documents[{document_id,version,title,node_id,can_index,state,indexed_version,chunk_count,error_code,enabled}]。未選 project 僅列專案與設定，不抓全公司文件。
- `POST /rag/documents/{id}/index`：現行版索引，回文件狀態；`PUT /rag/documents/{id}/enabled` body {enabled:boolean}。
- `GET/PUT /rag/model`：{enabled,base_url,model,embedding_model}。只限既有 local_admin 規則。
- `POST /rag/ask`：{project_id,question,previous_question?:string}。回 {query_id,project_id,kind,engine,answer,warning,citations:string[],sources:Source[],retrieval_mode,synthetic:false,source_mode:'formal'}。
- Source：{source_id,chunk_id,document_id,version,title,project_id,node_id,excerpt,locator:{page?,section?,start_char?,end_char?}}。source_id = chunk ID；持久化 query 僅存來源識別，不存 excerpt。
- `GET /rag/queries/{query_id}/sources/{source_id}`：{document_id,version,title,text,locator,is_current,download_url}；限定該 query actor，live document permission。
- `PUT /rag/queries/{query_id}/feedback`：{rating:'helpful'|'unhelpful'}，不收自由文字以免意外存個資。
- `GET /rag/metrics`：admin 本公司聚合，無內容全文。

## 模組內部介面

- `parsing.parse_file(path, filename)` → list[{text,locator}]；`chunking.build_chunks(sections)` → list[{text,parent_text,parent_id,locator}]，純函式不得查 DB。
- `retrieval.rank(question, candidates, query_vector=None, limit=6, budget=8000)` → list candidate（保留來源欄位，excerpt父文字裁切），candidates 已授權且現行，每筆含 text,parent_text,parent_id,embedding,chunk_id 等。`retrieval.expand_query(question, previous_question=None)` → str。
- `provider.embed(config,texts)` → list vectors，config embedding_model；`provider.answer(config,question,sources)` → {answer,citations}，傳入 source_id/excerpt。無效輸出 raise ValueError，不直接記原始例外。
- `governance.authorized_documents(db,current,project_id)` → list Document；`governance.recheck(db,current,document_id,version,require_current=True)` → DocumentVersion（拒絕 raise HTTPException）。重用 document_store。
- `governance.trace_summary(**fields)` → 白名單 dict；`evaluation.evaluate(cases, run)` → JSON report，純 runner。

## 介面衝突檢查

| 配對 | 檢查與決議 |
|---|---|
| A/B ↔ root | 純 dict／已授權候選，root 擁有 DB transaction、chunk ID、模型版本；pipeline 不查全公司資料。 |
| C ↔ root | 上列固定 API，前端自己向 status 取真實專案；不把舊 scope 文案當 ID。 |
| D ↔ root | D 授權只回 ORM／版本，root 再檢查 enabled/index；trace whitelist 在獨立 query 表不經 audit payload。 |
| 各任務自身 | 各副本只產出允許檔案、不 commit、不部署；root 合併後統一驗證，不以各自 mock 通過取代整合驗收。 |
