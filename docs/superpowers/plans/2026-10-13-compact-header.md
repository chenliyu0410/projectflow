# 專案標題區壓縮

依使用者指示，將新增子節點／模板下拉移至頂欄帳號左側；保留原專案與節點作用範圍、權限及停用條件，離開專案或載入時不顯示。專案總覽標籤與專案名稱同列，根專案不重複顯示同名路徑。子層保留返回導覽；編輯節點仍在節點標題區。手機帳號縮為頭像，選單功能保留，長標題可換行。
