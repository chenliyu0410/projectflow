# 捲軸、專案次層導覽與連接頁籤

2026-10-13 使用者要求三項前端調整，並確認專案採右側第二層面板。在 `feature/ux-child-modules-navigation` 延續實作。

## 範圍與設計
- 全站原生捲動保留；捲動時顯示細捲軸，停止約 900ms 後淡出，尺寸固定避免版面跳動。游標靠近捲動邊緣時亦可顯示以供拖曳；高對比模式保留系統可辨識顏色。
- 主導覽保留一個「專案」入口；右側面板呈現完整名稱、進度與新增入口。選取、外部點擊或 Escape 關閉並合理還原焦點；手機改為窄螢幕面板，清單獨立捲動。
- 看板、時程、相依圖等共用同一頁籤內容容器，選中頁籤底色連接內容；窄螢幕頁籤橫向捲動。
- 不變更後端、資料模型、權限、帳號或既有業務資料；不合併、推送或部署。

## 允許檔案與步驟
1. `web/src/components/WorkspaceShell.tsx`、`NavIcons.tsx`：次層面板與入口。
2. `web/src/useScrollActivity.ts`、`main.tsx`：原生捲軸活動狀態。
3. `web/src/components/NodeWorkspace.tsx`、`styles.css`：頁籤與內容容器。
4. `web/src/*.test.tsx`、`web/e2e/*`：必要互動驗證，既有測試依新入口調整。
5. `README.md`、`docs/PROGRESS.md`、本文件：交付與限制。

## 驗收
執行型別檢查與建置、受影響前端測試；隔離預覽於桌面 1280×720／手機 375×667 驗專案開關、焦點、長名稱／捲動、頁籤與內容連接；完成一次唯讀獨立審查。結果統一記錄 PROGRESS，不修改展示資料。
