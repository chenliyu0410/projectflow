# 使用者頂欄、浮動副手與操作下拉

依2026-10-13使用者指示，在現有功能分支完成三項局部前端調整。

- 使用者姓名與頭像移到右上角，展開保留公司、角色、切換公司與登出。
- AI專案副手預設收合，右下角圖示展開浮動面板；關閉/Escape返回圖示焦點，收合保留同一位置的輸入與對話。主內容不再保留右側350px欄位。
- 另存為模板、套用模板、新增子節點收成下拉，入口顯示第一項可見操作。保持原權限、停用條件與各自表單；編輯節點仍獨立。
- 桌面與手機均需可用，選單外部點擊/Escape可關閉。只改web呈現與對應測試，不改後端或業務資料，不推送/合併/部署。

允許檔案：WorkspaceShell、CopilotPanel、App、styles、共用Dropdown元件；web/src單元測試與測試導覽工具、web/e2e受影響入口及新驗收；README、PROGRESS、本文件。
實作順序：共用展開元件→使用者頂欄與副手→操作下拉→單元/型別/build及1280/375真瀏覽器驗收→一次獨立唯讀審查→交付記錄與本機提交。
驗收聚焦位置、無溢位、預設收合、內容不被右欄壓縮、選單焦點與各操作表單入口/取消、原權限與副手收合保留輸入。結果記PROGRESS。
