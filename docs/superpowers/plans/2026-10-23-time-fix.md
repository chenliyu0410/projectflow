# TIME-FIX：中文時間檢索與時間區間（A03／S01，隔離版）

依人類2026-10-23「A03跟S01繼續修」。改之前先凍結第三份獨立題庫 `holdout-3.jsonl`（26題，含9題時間說法），commit `51544c5`，基準以 `--summary-only` 只看總分；第一、二份題庫改為開發題庫。

## 修改

- 檢索：`store.time_hints()` 把問題中的中文時間（十點半、下午三點、十一點四十五分…）轉成 HH:MM，`search_text()` 只用於關鍵字與語意檢索（入門文件與正式文件皆同），模型看到的問題仍是原文。
- 送給模型的內容加 `question_times`；提示加「時間區間 A–B：A 是開始、B 是結束」與「是非題先答是否，再說具體內容」。
- 伺服器：開頭即「資料未記載」的回答，即使沒有引用也轉成固定拒答（原本會因引用驗證失敗退回原文）。
