# AI 副手示範題目（隔離試用版）

全部是虛構資料。題目、必須出現的內容與權限檢查存在 [demo-questions.json](../deploy/rag-starter/evaluation/demo-questions.json)，示範前可以先自動跑一次，確認每題都還答得對。

## 示範前準備

1. 啟動隔離副本（見[交接檔](LOCAL_AI_HANDOFF.md#啟動及試用)），開啟 http://127.0.0.1:15176。
2. 確認題目都通過（暖機後約 1–2 分鐘，首次載入模型較久；只查詢、不改資料）：

```powershell
.\.venv\Scripts\python.exe deploy/check_demo_questions.py --report ../output/rag-starter-acceptance/local-model/demo-check.json
```

3. 以 `yu`／`demo-yu` 登入，右下角開啟 AI 副手。副手上方應顯示「本地模型：pf-qwen3-rag:latest」與「語意檢索：bge-m3」。

每則回答下方可展開「資料處理紀錄」，看到資料等級、送給模型的段落數、檢索方式（關鍵字＋本地語意向量），以及雲端關閉。「模型引用」標記的才是回答宣告依據的來源。

## 示範時避開或要說明的地方

- 遮罩是規則式的：數字比例、金額、電話、Email 與已登記的廠商名稱可以抓到，「提高到六成」這類自由文字抓不到，所以機密文件整份不送雲端。

- 4B 本地模型偶爾照抄來源未標時態的句子，例如門禁卡「10月26日由林怡安發給新人」，可能寫得像已經發了（資料基準日是10月20日）。示範時以展開來源為準，不要用這題示範時態。
- 回答引用有效，不代表每一句推論都正確；示範時請展開「模型引用」核對。
- 這是開發題庫，不是獨立盲測的準確率。
